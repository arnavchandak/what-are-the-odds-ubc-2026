# Demo walkthrough

Run `npm run demo`, open [the judge preview](http://127.0.0.1:4178/), and follow the walkthrough. The article, markets and prices in this preview are fictional. The popup, chart, controls and settlement view are the same UI used by the extension.

| Time | Show |
| --- | --- |
| 0:00–0:25 | A news article can make a prediction question obvious, while finding the exact contract takes several tabs. Introduce the popup and label the sample data. |
| 0:25–1:05 | Point to the color-coded latest odds above the chart. Switch to **30D**, then use **Outcomes** to hide one series. |
| 1:05–1:35 | Open **Context**. Read the short article connection and settlement excerpt. Return using **Back to odds**. |
| 1:35–2:15 | Explain how Claude matches candidates and how Gemini event and candle endpoints supply data in the live extension. Point to the README, live Gemini verification and the local demo trading account. |

For an installed-extension demo, follow the [live setup](../README.md#chrome-extension-with-live-markets) and use a fresh article with a relevant market. Demonstrate live API calls only if you are willing to send that article excerpt to Anthropic and incur usage. The archived [live Gemini endpoint check](GEMINI_VERIFICATION.md) is distinct from the sample popup preview.

The Devpost entry needs the final 2–3 minute video on YouTube or Google Drive with judge access.
